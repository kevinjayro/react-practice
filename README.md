# React Practice

A collection of React exercises written in TypeScript.

Focused on clean code, type safety, and common frontend patterns.

## Structure

Exercises are organized by topic. Each one includes a solution and optional alternative implementations.

## Goals

- Build React components and UI patterns
- Strengthen TypeScript and type safety
- Practice problem solving with real-world patterns
- Explore multiple implementation approaches

## Notes

- Solutions prioritize readability and maintainability
- Exercises are intended for practice and experimentation
- Alternative solutions are encouraged
